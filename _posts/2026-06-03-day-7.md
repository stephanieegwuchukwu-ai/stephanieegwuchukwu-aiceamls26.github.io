what_i_learned: |
  Today, I learned several new Python concepts that helped strengthen my programming skills. We reviewed functions and learned the difference between parameters and arguments. I learned that a parameter is the variable defined in a function, while an argument is the actual value passed into the function when it is called. We also spent time working with lists, which are used to store multiple pieces of data in one place. I learned that lists use zero-based indexing, meaning the first item starts at index 0, and we practiced adding, removing, printing, and modifying items within a list, using functions like ".sort()", ".append()", .pop(), etc. I also learned how it can be used to organize items in a list alphabetically or numerically. During our research session, we continued loading the dataset for AI modeling research and reviewed a Pytorch tutorial video, which helped break down how to actually speed up deep learning data pipelines in PyTorch. It shows you how to use the built-in Dataset and DataLoader classes to handle batch training way more efficiently than the basic methods. In Figma 101, we looked over some student models. I actually got to present mine a few days back, so it was interesting to see how everyone else approached theirs. It felt good to see how these programming basics actually tie into real research work.
