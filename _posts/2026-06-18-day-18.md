what_i_learned: |
    Today was a shorter workday, but I still learned a lot while reviewing and improving my baseline 1D-CNN model for ECG classification. I spent time going through my code line by line and discovered that I had not trained the model using all three required random seeds as instructed. After reviewing the code more carefully, I corrected the issue and retrained the model using the three assigned seeds (42, 123, and 2026). This helped me better understand the purpose of using multiple seeds during training and how they help evaluate whether a model performs consistently rather than relying on a single run. I also learned more about model checkpoints and why they are useful. I revised my code to save a trained 1D-CNN model checkpoint to Google Drive. Instead of saving all three trained models, I saved one checkpoint that can be reused later for analysis and future experiments. This helped me understand how researchers can avoid retraining a model every time they want to test fairness metrics or perform additional evaluations. Another thing I learned was the importance of balancing training time with available resources. While the original project used 60 epochs, our graduate mentor had us use 15 epochs because we do not have access to paid Google Colab resources. Training for fewer epochs will allow us to complete experiments more efficiently while still being able to learn the workflow and analyze the model's performance. Also, from Dr. Gittens' lecture series, I learned how AI is evolving from basic chatbots to more advanced agents that can use tools, complete tasks, and support software development, while still requiring human oversight and accountability.
