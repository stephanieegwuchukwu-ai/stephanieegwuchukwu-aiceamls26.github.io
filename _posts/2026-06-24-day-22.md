    Today I learned how machine learning starts with splitting a dataset into features (X) and a target variable (y). I also reviewed why we divide data into training and testing sets (usually 80/20), so the model can learn from one portion and then be evaluated on unseen data. I was already familiar with data splitting from my research work, where the dataset is structured into 10 folds, with roughly 80% used for training and the remaining 20% split into validation and test sets (for example folds 1–8 for training, 9 for validation, and 10 for testing). I also learned that shuffling the data and setting a fixed random state helps ensure results are consistent and reproducible, so the model produces the same output when rerun under the same conditions. In my research, I used seed 42 as a global random seed, and I trained my model using a single seed for now, with plans to later extend it to training across three different seeds for more robust evaluation. We then explored different machine learning models like logistic regression, KNN, decision trees, and random forests. These were new to me, and I learned that each model learns patterns in different ways. Finally, I learned how multiple models can be trained and compared using loops or pipelines to evaluate which performs best on the test data.
